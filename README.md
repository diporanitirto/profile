## Tentang

Website satu halaman untuk memperkenalkan Ambalan Diporani Tirto, satuan pramuka penegak di SMAN 1 Kasihan, Bantul, DI Yogyakarta. Halaman menampilkan hero section dengan slideshow foto kegiatan, tagline yang diketik otomatis, dan informasi kontak.

## Fitur

- Hero section dengan background slideshow yang ganti otomatis setiap 5 detik.
- Tagline dengan efek typing yang bergantian antara dua kalimat.
- Navbar floating pill yang berubah jadi menu di mobile.
- Halaman satu scroll dengan tiap section memenuhi satu layar.
- Foto hero cukup taruh di folder `public/assets/images/` tanpa mengubah kode.

## Tech Stack

| Layer | Teknologi |
|---|---|
| Framework | Next.js 15 (App Router), React 19 |
| Bahasa | TypeScript 5 |
| Styling | Tailwind CSS 4 |

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000.
